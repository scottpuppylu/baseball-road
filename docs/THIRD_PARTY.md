# 素材及外部服務

球場SVG、角色Canvas rig與WebAudio短音為本專案原創。未打包真人照片、外站Logo、參考網站截圖、外部音效或音樂。插畫不是真人外貌。

Noto Sans TC以Google Fonts stylesheet取得，使用SIL Open Font License 1.1；未修改字體或將其單獨銷售。授權來源：[Noto CJK Sans LICENSE](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE)。

球員姓名、背號與打擊資料來源為允許公開的scottpuppylu/baseball-stats data分支logs.json，僅HTTPS GET。人物故事、性格、對話與關係皆為虛構，不從棒球統計推測私人生活。新遊戲不抓取avatars。

必要外連為GitHub公開資料與Google Fonts／字型資源；遊戲沒有分析追蹤、帳號系統、server API、個人進度上傳或canonical write。GitHub Pages與字體供應商按自己的服務規則處理一般HTTP請求。

Playwright是開發／CI用工具，未打包至production。Production沒有npm runtime dependency。
